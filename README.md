# To-Do App (Jetpack Compose)

Aplicación Android para la gestión de tareas (*To-Do List*) desarrollada como práctica sobre el manejo de estado y componentes dinámicos en **Jetpack Compose**.

## Características
- **Gestión de estado:** Manejo dinámico de tareas mediante `State`, `remember` y `mutableStateListOf`.
- **Componentes reutilizables:** Reutilización de elementos de la interfaz para mantener un código limpio y mantenible.
- **Interacción en tiempo real:** Actualización instantánea al agregar, marcar o eliminar tareas.
- **Recursos centralizados:** Organización de cadenas y texto en los archivos de recursos (`strings.xml`).

## Tecnologías utilizadas
- Kotlin
- Jetpack Compose
- Android Studio
